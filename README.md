# HotelGenDigital

🏨 **HotelGenDigital** - Akıllı Otel Yönetim Platformu

## Proje Hakkında
HotelGenDigital, otel operasyonlarını dijitalleştiren ve yapay zeka destekli akıllı yönetim çözümleri sunan kapsamlı bir platformdur.

## Teknolojiler
- Next.js / React
- Supabase
- Vercel
- Telegram Bot API
- OpenAI / Claude AI

## Modüller
- 📋 Rezervasyon Yönetimi
- 🤖 AI Destekli Misafir İletişimi
- 📊 Departman Yönetim Paneli
- 🔔 Akıllı Bildirim Sistemi

## Kurulum
```bash
git clone https://github.com/kemalkuyucu/hotelgendigital.git
cd hotelgendigital
npm install
npm run dev
```
